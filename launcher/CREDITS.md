## English

- **N3 Recompiled** — WK2D. The native Windows recompilation of *N3: Ninety-Nine Nights* this launcher builds on.
  <https://github.com/WK2D/N3-Ninety-Nine-Nights-Recomp>. Its repository declares no license, so this repository **does not redistribute its code or
  binaries**: the launcher works alongside the release the user downloads from its author.
- **ReXGlue SDK** — Tom Clay and contributors (BSD 3-Clause), partly derived from **Xenia** (Ben Vanik and contributors). The finding about
  `XGetLanguage` that explains why the language cannot be chosen came from reading its public source.
- **Cinzel** (Natanael Gama / Ndiscover) and **Cormorant Garamond** (Christian Thalmann / Catharsis Fonts) — SIL Open Font License 1.1.
- **Electron / Chromium** — their respective authors and licenses, shipped with the release.
- **Design**: the layout follows common game-launcher patterns and the "liquid glass" material follows ideas collected at
  <https://liquidglassdesign.com/>; no code or assets were copied from those sites.
